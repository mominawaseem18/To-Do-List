
# 📝 To-Do List App

A simple and responsive **Todo App** built with **React.js**. This project allows users to add, manage, and delete tasks through a clean and user-friendly interface.

## 🚀 Live Demo

👉 [View Live Project](https://my-todo-project-7392.netlify.app/)

## 📌 About The Project

This Todo App was created as a React.js practice project to understand the fundamentals of React, including:

* React Components
* `useState` Hook
* Event Handling
* Props
* List Rendering
* JavaScript Array Methods
* Local Storage
* CSS Modules
* Component-based UI development

The application provides a simple way to manage daily tasks.

## ✨ Features

* ➕ Add new tasks
* 📝 Display tasks dynamically
* 🗑️ Delete tasks
* 💾 Store tasks using Local Storage
* 🔄 Update the UI dynamically
* 📱 Responsive design
* 🎨 Clean and simple interface
* ⚛️ Built with React components

## 🛠️ Technologies Used

* **React.js**
* **JavaScript (ES6+)**
* **HTML5**
* **CSS3**
* **CSS Modules**
* **Local Storage**
* **Netlify**
